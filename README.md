# Christopher Nokes — GitHub Pages Profile

A simple static profile website with three pages:

- `index.html` — Home
- `research.html` — Research & Academic
- `other.html` — Other / Experience / Projects

## Deploy on GitHub Pages

1. Create a repository named `<username>.github.io`.
2. Upload the contents of this folder to the repository root.
3. Commit and push.
4. In GitHub, open **Settings → Pages** and select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

The site has no build system or external dependencies.

## Profile image

Put a photo at:

`images/profile.jpg`

The Home page will automatically display it. Other images can be added under `images/` and referenced from HTML with normal relative paths.
